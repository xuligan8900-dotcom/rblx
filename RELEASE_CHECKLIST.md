# Release checklist

- [x] Source project, build command, core simulation and local regression tests.
- [x] Local place artifact generated; no experience published.
- [ ] Run every Studio scenario in TEST_PLAN.md and record evidence.
- [ ] Validate existing profile integrity, simultaneous servers, outages and crash recovery.
- [ ] Finish missing systems in DEVELOPMENT_PROGRESS.md or explicitly revise release scope.
- [ ] Full Roblox-aware type analysis, accessibility, gamepad and real-device performance review.
- [ ] Add original/licensed audio and other art; record asset ownership and permissions.
- [ ] Keep paid products disabled until real IDs, ProcessReceipt ledger and recovery tests exist.
- [ ] Set universe maximum players to 8, private staging visibility and test-only API access.
- [ ] Publish privately through Studio → File → Publish to Roblox; test in Roblox client.
- [ ] Review content, security and current Roblox policies before making public.

No external credentials, fabricated asset IDs, paid random items, automated publishing or token handling are part of this increment. Product IDs are intentionally absent; there is no payment prompt or receipt handler.
